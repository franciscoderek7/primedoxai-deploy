Authentication

POST /auth/register No auth
Create a new user account. Stores credentials in Supabase Auth. Returns a signed JWT.
Request Body
FieldTypeRequiredDescription
emailstringrequiredUser email
passwordstringrequiredMin 6 chars
namestringoptionalDisplay name
referral_codestringoptionalReferral code for discount
Response 200
{ "token": "eyJ...", "user": { "id": "uuid", "email": "...", "role": "customer" } }
409 — Email already registered
POST /auth/login No auth
Login with email + password. Returns a 7-day JWT (configurable via JWT_EXPIRES_IN).
Request Body
FieldTypeRequiredDescription
emailstringrequired
passwordstringrequired
Response 200
{ "token": "eyJ...", "user": { "id": "uuid", "email": "...", "role": "customer" } }
401 — Invalid credentials
POST /auth/refresh JWT required
Extend a valid JWT. Returns a fresh token with reset expiry. Call before token expires to keep sessions alive.
Response 200
{ "token": "eyJ..." }
GET /auth/me JWT required
Returns the authenticated user's profile.
Response 200
{ "id": "uuid", "email": "...", "role": "customer", "name": "..." }
POST /auth/logout JWT required
Invalidate the current session in Supabase. JWT is stateless — client should also delete the stored token.
Response 200
{ "message": "Logged out" }
POST /auth/reset-password No auth
Trigger a Supabase password reset email.
FieldTypeRequiredDescription
emailstringrequired
Response 200
{ "message": "Password reset email sent" }

AI Routing

Fallback chain: Claude (Anthropic) → OpenAI/DeepSeek → Qwen → GLM → Kimi. First configured provider wins.

POST /api/ai/route JWT required
Route a chat completion request through the AI fallback chain. Used by Kimi's frontend for all AI-powered features.
FieldTypeRequiredDescription
messagesarrayrequiredOpenAI-format message array: [{role,content}]
systemstringoptionalSystem prompt override
max_tokensnumberoptionalDefault: 1024
temperaturenumberoptionalDefault: 0.7
Request Example
{ "messages": [ { "role": "user", "content": "Summarize Ontario cannabis regulations" } ], "max_tokens": 500 }
Response 200
{ "content": "Ontario cannabis retail...", "provider": "anthropic", // which AI responded "model": "claude-haiku-4-5-20251001", "usage": { "input_tokens": 12, "output_tokens": 84 } }
503 — All AI providers exhausted (no API keys configured)
POST /chat No auth (rate-limited)
Stateful multi-turn conversation with a specific PrimeDox AI agent. Session history held in memory (30 min TTL).
FieldTypeRequiredDescription
agent_idstringrequiredOne of: phoenix, counsel, barrister, ledger, archivist, alpha, and 39 others
messagesarrayrequiredFull message history
session_idstringoptionalPersist conversation across requests
Response 200
{ "reply": "...", "agent_id": "phoenix", "session_id": "sess_abc123" }
POST /swarm No auth (rate-limited)
Fan a single query out to multiple agents in parallel. Returns all responses. Max 8 agents per request (SWARM_MAX_AGENTS env var).
FieldTypeRequiredDescription
querystringrequiredPrompt to send to all agents
agent_idsstring[]requiredArray of agent IDs, max 8
Response 200
{ "results": [ { "agent_id": "phoenix", "reply": "..." }, { "agent_id": "counsel", "reply": "..." } ] }

Gap Scanner

Scans any public business website, scores it 0–100 against industry benchmarks, and generates an AgentForge quote. Higher gap score = more revenue opportunity.

POST /api/gap-scan No auth
Full gap analysis: fetch → detect industry → score 7 categories → return prioritized gaps + AgentForge quote.
FieldTypeRequiredDescription
urlstringrequiredBusiness website URL (http:// or https://)
industrystringoptionalOverride auto-detect: dental, restaurant, legal_criminal, etc.
Response 200
{ "success": true, "url": "https://example-dentist.com", "domain": "example-dentist.com", "detected_industry": "dental", "gap_score": 72, // 0-100, higher = more opportunity "gap_score_label": "HIGH — Significant missed opportunity", "present_score": 28, "gaps_found": [ { "id": "no_booking", "priority": "HIGH", "title": "No online booking system detected", "impact": "72% of dental competitors have online booking", "fix": "Deploy Booking Agent — 24/7 appointment scheduling", "agent": "booking_agent", "monthly_value_cad": 800 } ], "agentforge_quote": { "agents_recommended": [{ "id": "booking_agent", "setup": 297, "monthly": 97 }], "setup_cost_cad": 950, "monthly_cost_cad": 340, "bundle_discount_pct": 20, "roi_breakeven_months": 3, "paypal_url": "https://paypal.me/derekfranciaco1/950CAD" } }
GET /api/gap-scan/industries No auth
List all 20 supported industries with their sub-industry breakdowns.
Response 200
[ { "id": "dental", "group": "Healthcare", "industry": "dental", "sub_industries": ["general", "orthodontics"] }, ... ]
POST /api/gap-scan/batch No auth
Scan up to 5 URLs in parallel. Ideal for agency prospecting lists.
FieldTypeRequiredDescription

// Array of scan results, one per URL (same schema as single scan) [ { "success": true, "url": "...", "gap_score": 68, ... }, ... ]

Agent Marketplace

Revenue split: 70% creator / 20% platform / 10% operations. Stripe Checkout handles payment. PayPal fallback if Stripe not configured.

GET /api/marketplace/agents No auth
Paginated agent catalog with optional filters.
Query ParamTypeDescription
categorystringFilter by: Operations, Lead Capture, Reputation, Marketing, Intelligence, Retention
industrystringFilter by industry ID (e.g. dental)
featuredboolOnly featured agents
searchstringFull-text search on name/tagline/description
pagenumberDefault: 1
per_pagenumberDefault: 20, max: 50
Response 200
{ "agents": [ { "id": "booking_agent", "name": "Booking Agent", ... } ], "total": 10, "page": 1, "per_page": 20, "source": "catalog" // "catalog" | "supabase" | "catalog_fallback" }
GET /api/marketplace/agents/:id No auth
Full agent detail including recent reviews.
Agent IDs

booking_agent, chat_agent, review_agent, seo_agent, lead_agent, intake_agent, reminder_agent, follow_up_agent, analytics_agent, social_agent

POST /api/marketplace/agents/:id/purchase No auth
Create a Stripe Checkout session. Redirects customer to Stripe-hosted payment page. Returns PayPal fallback URL if Stripe not configured.
FieldTypeRequiredDescription
customer_emailstringoptionalPre-fill Stripe checkout email
success_urlstringoptionalRedirect after payment. Default: /marketplace/success
cancel_urlstringoptionalRedirect on cancel
Response 200 (Stripe configured)
{ "checkout_url": "https://checkout.stripe.com/...", "session_id": "cs_live_..." }
Response 200 (PayPal fallback)
{ "checkout_url": "https://paypal.me/derekfranciaco1/297CAD", "amount_cad": 297 }
POST /api/marketplace/agents/:id/reviews JWT required
Submit a review for a purchased agent. One review per user per agent.
FieldTypeRequiredDescription
ratingnumberrequired1–5
review_textstringrequiredMin 10 chars
reviewer_namestringoptionalDisplay name. Default: Anonymous
POST /api/marketplace/submit JWT required
Submit a new agent to the marketplace (creator flow). Goes to pending_review status. 48h review turnaround.
FieldTypeRequiredDescription
namestringrequiredAgent display name
taglinestringrequiredOne-line value proposition
descriptionstringrequiredFull description
categorystringrequiredOperations / Lead Capture / Marketing / etc.
setup_price_cadnumberrequiredOne-time setup fee
monthly_price_cadnumberoptionalRecurring monthly fee
industriesstring[]optionalTarget industry IDs (or ["all"])
skillsstring[]optionalCapability tags
Response 200
{ "success": true, "message": "Agent submitted for review. We'll contact you within 48 hours.", "agent_id": "..." }

Payments

POST /webhooks/stripe Stripe signature
Stripe webhook endpoint. Do not call directly. Configure in Stripe Dashboard → Webhooks.
Requires raw body (not JSON-parsed). Header: stripe-signature. Secret: STRIPE_WEBHOOK_SECRET env var.
Handled Events
EventAction
checkout.session.completedWrite payment to payments table; trigger referral commission if applicable
payment_intent.succeededUpdate payment status to succeeded
customer.subscription.createdWrite subscription record; update user profile
customer.subscription.deletedMark subscription cancelled; revoke access
Webhook URL
https://YOUR-URL.railway.app/webhooks/stripe
