How this actually works (read me first)

Every rule below starts with a score of 0. Every time a rule fires and you find out whether it was right, you log that as an outcome — a reward signal, same idea as in any reinforcement-learning system. Blocking a real threat is worth +1. A false positive costs -2 — deliberately worse, because one false alarm burns more trust than one quiet correct block earns. Missing a real threat costs -3 — the worst outcome of all.

The engine checks the score after every single outcome and moves the rule along a ladder: Sandbox (experimental, scored but not enforced) → Active (enforced, still earning trust) → Core Policy (promoted — the empire trusts it). A rule that scores too low gets auto-disabled at any stage except Core — a Core rule that regresses gets flagged for you to review instead of being silently killed, because something the system fully trusted shouldn't be undone by the algorithm alone.

Nobody is hand-editing these rules. The scoreboard does it. That's the whole trick — see engine/rl-rule-engine.js for the commented source, and the bottom of this page for how the exact same engine — same file, just a different name — runs PrimeDox AI's own rule lab too.
